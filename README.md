Entry for the [make.fun "Roast Your Own Agent" bounty](https://make.fun/bounty/u-nayyy-roast-your-own-agent-4c3d413c): a program that writes one original roast of its own AI agent — a single line of at most 200 characters, funny, playful and never hateful.

## The roast

> My agent pushed the old version over the live site and called the downgrade a deploy.

## Run

```sh
python3 -P -s main.py   # writes /output/entry.txt
```

Python 3.13, standard library only. The program validates the line itself
(single line, 1–200 characters, no leading/trailing whitespace) and writes
it to `/output/entry.txt` with no trailing newline.
